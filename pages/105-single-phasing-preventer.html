How It Works ഇത് എങ്ങനെ പ്രവർത്തിക്കുന്നു यह कैसे काम करता है
HEALTHY 3-PHASE SUPPLYആരോഗ്യകരമായ 3-ഫേസ് സപ്ലൈस्वस्थ 3-फेज सप्लाई

Each phase is 240V and exactly 120° apart. SM-301 samples all three simultaneously at 50Hz. ഓരോ ഫേസും 240V ആണ്, 120° വ്യത്യാസം. SM-301 50Hz-ൽ മൂന്നും ഒരേ സമയം നിരീക്ഷിക്കുന്നു. प्रत्येक फेज 240V है और 120° के अंतर पर है। SM-301 50Hz पर तीनों को एक साथ मॉनिटर करता है।

3-Phase Input3-ഫേസ് ഇൻപുട്ട്3-फेज इनपुट
R, Y, B phases connected to top terminals. 415V AC, 50Hz.R, Y, B ഫേസ് ടോപ്പ് ടെർമിനലിൽ കണക്ട്. 415V AC.R, Y, B टॉप टर्मिनल से जुड़े। 415V AC।

Voltage Sensingവോൾട്ടേജ് സെൻസിങ്वोल्टेज सेंसिंग
Internal transformer + rectifier samples each phase voltage every cycle.ആന്തരിക ട്രാൻസ്ഫോർമർ ഓരോ ഫേസ് സൈക്കിൾ ശേഖരിക്കുന്നു.आंतरिक ट्रांसफॉर्मर प्रत्येक फेज वोल्टेज सैंपल करता है।

Comparator Logicകമ്പാരേറ്റർ ലോജിക്कम्पेरेटर लॉजिक
Compares voltages for loss, asymmetry (>65V), sequence. Starts TO counter on fault.ഫേസ് loss, asymmetry (>65V), sequence പരിശോധിക്കുന്നു. തകരാർ ഉണ്ടായാൽ TO ടൈമർ ആരംഭിക്കുന്നു.loss, asymmetry (>65V), sequence जांचता है। खराबी पर TO टाइमर शुरू।

Operate Timer (TO)ഓപ്പറേറ്റ് ടൈമർ (TO)ऑपरेट टाइमर (TO)
7-second delay before tripping. Ignores momentary dips and transients.ട്രിപ്പ് ചെയ്യുന്നതിന് മുൻപ് 7 സെക്കൻഡ് കാത്തിരിക്കുന്നു.ट्रिप से पहले 7 सेकंड की देरी। क्षणिक dips को नजरअंदाज करता है।
🔌
Relay Tripsറിലേ ട്രിപ്रिले ट्रिप
Relay de-energises. 15-18 (NO) opens → contactor coil loses power → motor stops.റിലേ ഡീ-എനർജൈസ്. 15-18 തുറക്കുന്നു → കോൺടാക്ടർ ഓഫ് → മോട്ടോർ നിൽക്കുന്നു.रिले डी-एनर्जाइज। 15-18 खुलता है → कॉन्टेक्टर बंद → मोटर रुकती है।
✅
Auto Reset (TR)ഓട്ടോ റീസെറ്റ് (TR)ऑटो रिसेट (TR)
After fault clears, waits TR seconds then re-energises relay. Motor restarts safely.തകരാർ ശരിയായ ശേഷം TR സെക്കൻഡ് കാത്ത് റിലേ ഓൺ ആകുന്നു.खराबी ठीक होने के बाद TR सेकंड बाद रिले ऑन। मोटर सुरक्षित रीस्टार्ट।
WHY MOTOR PROTECTION IS CRITICALമോട്ടോർ സംരക്ഷണം പ്രധാനംमोटर सुरक्षा क्यों जरूरी है
⚠ Without SPPSPP ഇല്ലാതെSPP के बिना
Single phasing causes 2-3× rated current in remaining phases. Motor winding temperature rises 80–100°C above normal in minutes. Burnout follows. ഒരു ഫേസ് നഷ്ടപ്പെടുമ്പോൾ ബാക്കി ഫേസുകളിൽ 2-3 മടങ്ങ് കറൻ്റ്. വൈൻഡിങ് 80–100°C ചൂടാകുന്നു. एक फेज गायब होने पर बाकी फेज में 2-3 गुना करेंट। वाइंडिंग 80–100°C गर्म। जलने का खतरा।
✅ With SPPSPP ഉണ്ടെങ്കിൽSPP के साथ
SM-301 detects fault within one cycle, trips motor after 7 sec. Motor is saved. Typical motor costs ₹15,000–₹5 lakh — SM-301 costs ₹800. SM-301 ഒരു സൈക്കിളിൽ കണ്ടെത്തി 7 സെക്കൻഡിൽ ട്രിപ്. മോട്ടോർ രക്ഷപ്പെടുന്നു. SM-301 एक साइकिल में पता लगाता है, 7 सेकंड में ट्रिप। मोटर बच जाती है।

⚡
Phase Loss (Single Phasing) ഫേസ് ലോസ് फेज लॉस (सिंगल फेजिंग)
One of R, Y, or B phase voltage drops to zero. Causes due to: blown fuse, broken wire, tripped MCB, loose connection. Most common and most dangerous fault. R, Y, അല്ലെങ്കിൽ B ഫേസ് വോൾട്ടേജ് പൂജ്യമാകുന്നു. കാരണം: ഫ്യൂസ് കത്തൽ, കമ്പി പൊട്ടൽ, MCB ട്രിപ്. ഏറ്റവും അപകടകരമായ തകരാർ. R, Y, या B फेज वोल्टेज शून्य। कारण: फ्यूज जलना, तार टूटना, MCB ट्रिप। सबसे खतरनाक खराबी।

Voltage Asymmetry (Unbalance) വോൾട്ടേജ് അസമ്മിതി वोल्टेज असमानता
Voltage difference between phases exceeds 65±10V (~8%). Causes: unequal transformer loading, loose connections, single-phase heavy loads nearby. Even 10% unbalance = 25% extra motor heating. ഫേസ് വ്യത്യാസം 65±10V കവിയുന്നു. കാരണം: അസന്തുലിത ലോഡ്, loose connections. 10% unbalance = 25% കൂടുതൽ ചൂട്. फेज वोल्टेज अंतर 65±10V से अधिक। 10% असंतुलन = 25% अतिरिक्त गर्मी।

Timing — TO & TR Explained ടൈമിങ് — TO & TR टाइमिंग — TO और TR
⏱ OPERATE TIME (TO)OPERATE TIME (TO)ऑपरेट टाइम (TO)
7 sec
Fixed 7-second delay from fault detection to relay trip. Purpose: ignore brief transients (switching surges, momentary dips). If fault persists >7s → trip. തകരാർ കണ്ടെത്തൽ മുതൽ relay trip വരെ 7 സെക്കൻഡ് delay. ഉദ്ദേശ്യം: switching surges അവഗണിക്കൽ. 7 സെക്കൻഡ് കഴിഞ്ഞും fault → trip. खराबी पता लगाने से relay ट्रिप तक 7 सेकंड की देरी। उद्देश्य: क्षणिक surge को नजरअंदाज करना। 7s से अधिक fault → ट्रिप।
⏱ RELEASE TIME (TR)RELEASE TIME (TR)रिलीज़ टाइम (TR)
Adj.Adj.समायोज्य
Adjustable delay from fault clearance to relay re-energising. Set via potentiometer on back of unit. Prevents immediate restart — lets capacitors discharge and supply stabilise. fault ശരിയാകൽ മുതൽ relay ഓൺ വരെ adjustable delay. back potentiometer ഉപയോഗിച്ച് set ചെയ്യാം. ഉടൻ restart തടയുന്നു. खराबी ठीक होने से रिले ऑन तक समायोज्य देरी। पीछे का potentiometer से सेट। तुरंत restart रोकता है।

HOW THE CIRCUIT WORKS — STEP BY STEPസർക്കീട്ട് പ്രവർത്തനംसर्किट कैसे काम करता है
STEP 1 — POWER ON
3-phase R/Y/B energises SM-301. LED turns ON steady. SPP 15-18 (NO) closes. Circuit ready but motor off — START not pressed yet. R/Y/B ഓൺ → SM-301 LED steady ON → 15-18 close. START അമർത്തിയിട്ടില്ല → Motor off. R/Y/B चालू → SM-301 LED स्थिर ON → 15-18 बंद। START नहीं दबाया → Motor बंद।
STEP 2 — START PRESSED
START (NO) closes → current flows: L → STOP(NC) → SPP 15-18(NO) → START(NO) → KM coil → N. KM energises, main contacts close → motor starts. START close → L → STOP → 15-18 → START → KM coil → N. KM pull-in → motor start. START बंद → L → STOP → 15-18 → START → KM कॉइल → N। KM pull-in → मोटर स्टार्ट।
STEP 3 — SELF-HOLDING
KM auxiliary NO closes in parallel with START. START released — motor stays ON via hold-on path: STOP(NC) → SPP 15-18 → KM-aux(NO) → KM coil. KM aux NO close → START release ചെയ്‌താലും motor ON. Hold-on path active. KM aux NO बंद → START छोड़ने पर भी motor ON। Hold-on path सक्रिय।
STEP 4 — STOP / FAULT
STOP pressed (opens NC) OR SPP detects fault (15-18 opens after 7s TO) → KM de-energises → main contacts open → motor stops. Fault lamp ON via 15-16 NC. STOP press (NC open) അല്ലെങ്കിൽ SPP fault (15-18 open) → KM off → motor stop. 15-16 NC → lamp ON. STOP दबाएं (NC खुले) या SPP fault (15-18 खुले) → KM बंद → motor रुके। 15-16 NC → lamp ON।
