❓ What is Pull-out?
Pull-out Torque = Maximum torque the motor can develop without losing synchronism.
At δ = 90°, motor loses lock with supply → speed drops → motor stalls.

To avoid pull-out:
• Increase field excitation (higher If → higher Ef → lower δ)
• Reduce mechanical load
• Never reduce If below minimum for that load
💡 Min. Excitation vs Load
Start motor and apply load to see analysis.
📚 Key Concepts
Why can't excitation reduce under load?
Load requires torque. Torque = (V·Ef·sinδ)/Xs. If Ef decreases, δ must increase to maintain torque. At δ = 90°, motor hits pull-out (stability limit).

Under-Excited (If low):
— Lagging power factor
— Motor absorbs reactive power
— δ is large → less stability margin

Normally Excited (If = rated):
— Unity power factor
— Minimum armature current
— This is the V-curve minimum

Over-Excited (If > rated):
— Leading power factor
— Motor supplies reactive power
— Acts as synchronous condenser
— Useful for power factor correction

Starting as Induction Motor:
Field is kept OFF. Motor accelerates like squirrel cage IM using damper windings. Near sync speed (~95%), field is switched ON to pull rotor into synchronism.
